# Day 02 — C Program Structure & Memory Basics

## Topics Learned
- What a program is in embedded systems
- Role of main() function
- What runs before main() (startup code)
- Compilation steps:
  - Preprocessing
  - Compilation
  - Linking
- Difference between header files and source files
- Where code and variables are stored in memory

## Key Understandings
- main() is not the first code to run
- Program code lives in flash memory
- Variables live in RAM
- Embedded programs usually run forever using while(1)
