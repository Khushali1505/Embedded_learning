# Day 01 — Embedded Systems Basics

## Topics Covered
- What is an embedded system
- Difference between MCU and MPU
- Introduction to STM32 and ESP32
- Firmware vs software
- Importance of power management
- Basic IoT architecture

## Key Takeaways
- Embedded systems are designed for specific tasks
- Firmware directly controls hardware
- Power and reliability are critical in embedded design
- Edge logic is preferred over cloud-only decisions
